# NovaMart — Full-Stack E-Commerce Store

NovaMart is a working online store: React frontend, Node.js/Express REST API and PostgreSQL database. It covers the complete shopping journey (browse → search/filter → cart → coupon → checkout → order tracking) plus an admin panel for products and order fulfilment.

| Layer | Tech |
|---|---|
| Frontend | React 18, React Router 6, Vite |
| Backend | Node.js 20, Express 5, Zod validation, JWT auth, bcrypt |
| Database | PostgreSQL 16 |
| API docs | OpenAPI 3 / Swagger UI at `/api-docs` |
| Deploy | Render Blueprint (`render.yaml`) or Docker Compose |

---

## Features

**Customer**
- Register / log in (JWT), persistent session
- Home page with featured products and categories
- Shop page: search, category filter, price range, in-stock filter, 5 sort options, pagination (state kept in the URL)
- Product page: stock status, sale pricing, quantity selector, related products, reviews (one per user)
- Server-side cart: add, update quantity, remove; stock limits enforced
- Checkout: delivery form with validation, coupon codes, Cash on Delivery or card (simulated gateway)
- Order history, order detail with status timeline, cancel order (restores stock)

**Admin** (`/admin`)
- Dashboard: revenue, orders, customers, recent orders, low-stock list
- Products: create, edit, deactivate (soft delete), search
- Orders: filter by status, view details, move through allowed status transitions

## Deploy online (free) — GitHub + Render

**Step 1 — Put the code on GitHub**
1. Create a new repository on GitHub, e.g. `novamart` (public or private).
2. In this folder run:
   ```bash
   git init
   git add .
   git commit -m "NovaMart e-commerce app"
   git branch -M main
   git remote add origin https://github.com/<your-username>/novamart.git
   git push -u origin main
   ```

**Step 2 — Deploy on Render**
1. Sign up at [render.com](https://render.com) with your GitHub account (no card needed).
2. Dashboard → **New** → **Blueprint** → select the `novamart` repo.
3. Render reads `render.yaml` and creates the database and the web service. Click **Apply**.
4. The first build takes about 3–5 minutes. Your store will be live at `https://novamart-xxxx.onrender.com`. The database is created and filled with demo data automatically on first start.

**Things to know about Render's free plan**
- The free web service sleeps after 15 minutes without traffic; the first visit after that takes about a minute to wake up. Open the site a minute before you present.
- Free Render Postgres databases expire **30 days** after creation. To keep the site running longer, either upgrade the database, or create a free Postgres on another provider (e.g. Neon or Supabase), then in Render → your web service → **Environment** set `DATABASE_URL` to that connection string and add `DATABASE_SSL=true`.
- `TEST_RESET_KEY` is auto-generated by Render (see the service's Environment tab). Your automation suite uses it to reset data (see below).

## Run locally

**Option A — Docker (easiest)**
```bash
docker compose up --build
```
Open http://localhost:4000

**Option B — Node + your own PostgreSQL**
```bash
# 1. Create a database called novamart in PostgreSQL
cp backend/.env.example backend/.env      # edit DATABASE_URL if needed
npm install --prefix backend
npm install --prefix frontend

# 2. Two terminals:
npm run dev:backend     # API on http://localhost:4000 (creates tables + seeds on first start)
npm run dev:frontend    # Website on http://localhost:5173 (proxies /api to the backend)
```
Reset demo data at any time: `npm run seed`

## Test data and business rules

These rules are fixed and deterministic, so they can be used directly as test oracles.

**Pricing**
- Currency PKR. Delivery is **Rs 250**, **free** when the subtotal is **Rs 5,000 or more** (checked on subtotal before discount).
- Total = subtotal − discount + delivery.

**Coupons**
| Code | Effect | Rule |
|---|---|---|
| `WELCOME10` | 10% off | Minimum subtotal Rs 2,000 |
| `FLAT500` | Rs 500 off | Minimum subtotal Rs 3,000 |
| `EXPIRED20` | — | Always fails: "This coupon has expired" |
| `INACTIVE15` | — | Always fails: "Invalid coupon code" |

**Cards** (simulated gateway: any future `MM/YY` expiry, any 3-digit CVV)
| Card number | Result |
|---|---|
| `4242 4242 4242 4242` | Success → order status `paid` |
| `4000 0000 0000 0002` | HTTP 402 "Your card was declined" |
| `4000 0000 0000 9995` | HTTP 402 "Insufficient funds on card" |
| Any other number failing the Luhn check | "Card number is invalid" |

Cash on Delivery orders start as `pending`.

**Order status flow:** `pending → paid → shipped → delivered`. `pending` and `paid` can go to `cancelled` (stock is restored). Any other transition returns HTTP 409.

**Seeded stock edge cases**
- Out of stock: *Orbit Wireless Earbuds*, *Mindful Cooking*
- Low stock: *Brew Pour-Over Coffee Kit* (2), *Echo Mini Bluetooth Speaker* (3), *Woollen Winter Shawl* (4), *Adjustable Dumbbell Set* (5)

**Validation rules**
- Password: minimum 8 characters, with at least one letter and one number
- Phone: Pakistani mobile — `03XXXXXXXXX` or `+923XXXXXXXXX`
- Postal code: exactly 5 digits

## Automation support

- **Stable selectors:** every interactive element and key piece of data has a `data-testid` (e.g. `login-email`, `add-to-cart`, `cart-item`, `summary-total`, `place-order`, `order-status`). List rows also carry IDs such as `data-product-id` and `data-order-number`.
- **Data reset endpoint:** `POST /api/test/reset` with header `x-test-reset-key: <TEST_RESET_KEY>` restores the seed data. It returns 404 when the key is missing or wrong, or when the server has no key configured.
- **API contract:** the OpenAPI spec is at `/api-docs/openapi.json` (use it for schema validation).
- **Consistent errors:** every error response has the shape `{ "error": { "code", "message", "details?": [{ "field", "message" }] } }`.

## API overview

Base URL: `/api` — full interactive docs at **`/api-docs`**

| Method | Endpoint | Auth |
|---|---|---|
| GET | `/health`, `/config` | – |
| POST | `/auth/register`, `/auth/login` | – |
| GET | `/auth/me` | User |
| GET | `/categories`, `/products`, `/products/:idOrSlug`, `/products/:idOrSlug/reviews` | – |
| POST | `/products/:idOrSlug/reviews` | User |
| GET / DELETE | `/cart` | User |
| POST | `/cart/items`, `/cart/coupon` | User |
| PATCH / DELETE | `/cart/items/:productId` | User |
| GET / POST | `/orders` | User |
| GET | `/orders/:id` | User |
| POST | `/orders/:id/cancel` | User |
| GET | `/admin/stats`, `/admin/users`, `/admin/orders`, `/admin/orders/:id` | Admin |
| GET / POST | `/admin/products` | Admin |
| PUT / DELETE | `/admin/products/:id` | Admin |
| PATCH | `/admin/orders/:id/status` | Admin |
| POST | `/test/reset` | Reset key |
